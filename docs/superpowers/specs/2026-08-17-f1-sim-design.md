# F1 Sim — дизайн

Дата: 2026-08-17
Статус: утверждён, готов к плану реализации

## Что строим

Браузерный симулятор Формулы-1 на three.js: реальные трассы, симуляционная физика
болида, тайм-триал с призраком, глобальный leaderboard топ-5 на трассу.

Живёт на `games.smolevich.com`, репо `Smolevich/f1-sim` — **публичный**.

Ключевое решение по глубине: это симулятор, а не аркада. Физика честная
(raycast-подвеска, слип-углы, температура шин), играбельность на клавиатуре
достигается **отключаемыми ассистами**, а не упрощением модели.

## Инфраструктура

```
games.smolevich.com          → Cloudflare Pages (статика игры)
games.smolevich.com/api/*    → Cloudflare Worker + KV (leaderboard)
```

Паттерн скопирован с работающего `smolevich-main-site` (Pages) и его воркера
`notes-share` (Worker + KV). Ничего нового не изобретаем.

- Зона `smolevich.com` = `673e637782ac48f81a7c86cf127e6f49`
- DNS: CNAME `games` → `f1-sim.pages.dev`, заводится API-токеном из Keychain
  (`security find-generic-password -s cloudflare-family-cli -w`)
- `game.smolevich.com` (единственное число) уже занят туннелем — не трогаем,
  наш поддомен `games`
- **Access не вешаем**: игра публичная

## Физика

### Шаг симуляции

Фиксированный **1/120 с** с аккумулятором, рендер — сколько вытянет железо.
Без этого на 144 Гц машина едет иначе, чем на 60, и рекорды несопоставимы.
Это требование к корректности leaderboard, а не оптимизация.

### Модель

Rigid body + **raycast vehicle**: 4 луча вместо колёс-коллайдеров. Так делают
все сим-движки — стабильнее и дешевле, чем честные цилиндры в солвере.

**Шины** (`tyres.ts`) — упрощённая Pacejka Magic Formula:
- продольный и боковой слип → сила
- круг трения: разгон и поворот одновременно = срыв
- температура: холодные не держат, перегретые тоже; окно ~90–110 °C
- износ по кругам, три состава (soft / medium / hard)

**Аэродинамика** (`aero.ts`):
- прижим ~ v², баланс перед/зад из сетапа
- лобовое сопротивление
- DRS: открытое крыло на прямых — меньше прижим, выше скорость

**Подвеска** (`vehicle.ts`):
- жёсткость и демпфирование на луч
- перенос веса при торможении и в поворотах — машина приседает и кренится,
  и это меняет сцепление на осях

**Трансмиссия** (`drivetrain.ts`):
- 8 передач, кривая мощности ДВС
- ERS: буст и рекуперация, ограниченный запас на круг

### Сетап

Перед заездом: угол крыльев, передаточные числа, давление шин, тормозной баланс,
состав шин. Сетап входит в запись результата.

### Ассисты

Каждый отключается независимо. Дефолт для клавиатуры — включены первые два.

| Ассист | Что делает | Дефолт |
|---|---|---|
| Сглаживание руля | цифровой ввод → плавный угол | вкл на клаве |
| Автокоробка | переключает передачи | вкл |
| Тракшн-контроль | режет тягу при пробуксовке | выкл |
| ABS | не даёт заблокировать колёса | выкл |
| Линия торможения | подсказка на трассе | выкл |

Набор ассистов пишется вместе со временем: заезды без ассистов в leaderboard
видно отдельно.

## Трассы

Шесть: **Монца, Монако, Спа, Сильверстоун, Сузука, Интерлагос**.

### Источник геометрии

Осевые линии — из **OpenStreetMap** (лицензия ODbL, свободная). Реальная геометрия
поворотов, а не рисованная от руки.

Пайплайн `scripts/build-track.ts`, гоняется один раз при разработке:

```
OSM way → сглаженный сплайн → полотно (ширина, виражи)
        → границы трассы и зоны срезки
        → отбойники, поребрики, простая геометрия окружения
        → track/<name>.json в репо
```

В рантайме игра ходит только в свой же JSON. Никаких обращений наружу.

**Рельеф** для Спа (Eau Rouge, перепад ~40 м) и Интерлагоса — из открытых данных
высот. Без вертикали Спа теряет смысл.

### Проверка

Длина сгенерированной трассы сверяется с официальной (Монца 5.793 км,
Монако 3.337 км, Спа 7.004 км и т.д.). Расхождение больше 2 % — трасса собрана
неверно, это тест, а не глазомер.

### Реальные рекорды круга

В конфиге трассы, для призрака-эталона и как верхняя планка валидации:

| Трасса | Рекорд | Кто, год |
|---|---|---|
| Монца | 1:21.046 | Баррикелло, 2004 |
| Монако | 1:12.909 | Хэмилтон, 2021 |
| Спа | 1:46.286 | Боттас, 2018 |
| Сильверстоун | 1:27.097 | Ферстаппен, 2020 |
| Сузука | 1:30.983 | Хэмилтон, 2019 |
| Интерлагос | 1:10.540 | Ферстаппен, 2018 |

Значения перепроверяются при реализации и хранятся в конфиге с указанием источника.

## Режим заезда: тайм-триал с призраком

Имя вводится на старте, живёт в localStorage.

- Три сектора на трассу, дельта к лучшему кругу в реальном времени
- Фиолетовые секторы (личный лучший)
- Призрак: полупрозрачный болид — свой лучший круг или темп реального рекордсмена
- Запись призрака: позиция + поворот на 20 Гц, ~50 КБ на круг, localStorage

Результат заезда = время лучшего круга → отправляется в leaderboard.

## Leaderboard

Worker + KV, топ-5 **на каждую трассу**.

```
GET  /api/leaderboard?track=monza  → топ-5
POST /api/leaderboard              → отправка результата
```

### Валидация на сервере

Клиентскую игру полностью защитить нельзя. Цель — отсечь очевидное, а не построить
анти-чит. Правила:

- время быстрее реального рекорда трассы → отклонить
- круг без всех трёх секторов → не засчитан
- срезка (выезд за границы) или ресет на круге → не засчитан
- вместе со временем шлётся: трасса, набор ассистов, сплиты по секторам, хеш призрака
- сумма секторов не сходится с временем круга → отклонить
- аномальный сектор (быстрее физически возможного) → отклонить
- rate limit по IP

Ограничение осознанное и зафиксировано здесь, чтобы следующая сессия не пыталась
«починить» его введением тяжёлого анти-чита.

## Модель болида

**База — процедурная геометрия по реальным пропорциям F1** (регламент):
длина 5.6 м, ширина 2.0 м, колёсная база 3.6 м, колёса 18", halo, антикрыло,
барджборды.

**GLTF-загрузчик — готовый путь рядом.** Если в ходе работы находится модель с
честной свободной лицензией (CC0 или CC-BY с атрибуцией), она подключается без
изменений в физике. Не находится — игра всё равно выходит.

Причина такой развязки: CC0-моделей болидов F1 мало, большинство на Sketchfab —
CC-BY или non-commercial. Вешать релиз на поиск ассета нельзя.

**Ливреи и команды — вымышленные.** Репо публичный, логотипы команд F1 — чужой
товарный знак. Стилистика реальная, названия свои.

## Тестирование

vitest, без моков собственного кода.

Чистые функции тестируются напрямую:
- `tyres`: холодная шина держит хуже прогретой; перегретая тоже; круг трения
  не даёт складывать полный разгон с полным поворотом
- `drivetrain`: ERS расходуется и восстанавливается, запас на круг не превышается
- `laptimer`: дельта считается верно; круг с срезкой не засчитан; сумма секторов
  сходится с временем круга
- `validation`: время быстрее рекорда трассы отклоняется
- `track/loader`: длина каждой собранной трассы сходится с официальной (±2 %)
- `ghost`: записанный и воспроизведённый круг совпадают по времени

Регрессионный тест на каждый пойманный баг, формулировка «баг не вернулся».

Физика проверяется ещё и **эталонными заездами**: круг на средней трассе должен
попадать в разумный коридор относительно реального рекорда. Если сим выдаёт
Монцу за 40 секунд — модель неверна, и это видно автоматически.

## Деплой

GH Actions по образцу `smolevich-main-site/.github/workflows/deploy.yml`, два job'а:

1. `pages deploy dist --project-name=f1-sim`
2. деплой Worker'а из `workers/leaderboard`

Worker деплоится из CI, а не руками: на main-site уже был случай, когда правка
воркера лежала в репо, а прод работал по-старому.

Секреты репо: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`.

### Публичный репо — что проверить до первого пуша

- ни одного токена, ID аккаунта, адреса сервера в коде и конфигах
- `.gitignore`: `node_modules/`, `.env`, `dist/`, `.wrangler/`
- ассеты только со свободной лицензией, источники записаны в `docs/assets.md`
- ливреи вымышленные, логотипов реальных команд нет
