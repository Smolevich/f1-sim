# F1 Sim — ощущение от езды, запись рекорда, интерфейс

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сделать так, чтобы болидом было приятно управлять: убрать дёрганость руля и заносы, сгладить камеру, начать записывать лучший круг, добавить Escape и название трассы.

**Повод.** Пользователь: «болид дёргается очень дёргано», «при любом повороте резко дёргает колёсами передними, из-за чего и заносы», «руль супер резкий», «нет клавиши Escape», «даже если плохо проехал круг, лучшее время не записывается», «не показывается название трассы», «ландшафт полуубогий», «болид похож на макет из Майнкрафта».

Проверено расчётом, все причины найдены:

1. **Руль вдвое быстрее реального.** Колёса поворачиваются со скоростью 120 град/с при реальных 60–70. Это моя прошлая правка: пользователь жаловался на вялый руль, я поднял `STEER_RATE` с 3.5 до 7.0 и перестарался.
2. **Угол руля не зависит от скорости — главная причина заносов.** На 200 км/ч физически полезен угол 2.6° (предел бокового ускорения 4 g при базе 3.6 м), а игра даёт все 17.2°. Любое нажатие на скорости срывает шины. Во всех гоночных симах угол ограничивают по скорости.
3. **Лучший круг не пишется из-за слишком строгой валидации.** `valid = false` ставится при ЛЮБОМ касании травы одним колесом. В реальной F1 круг аннулируют за выезд всеми четырьмя колёсами за белую линию, и только при повторных нарушениях.
4. **Escape не обрабатывается** — пауза только на `P`.
5. **Название трассы нигде не выводится**, хотя оно есть в `track.meta.name`.

**Architecture:** Руль — чистые функции в `keyboard.ts` и предел в `vehicle.ts`. Валидация — правило в `laptimer.ts`. Камера — сглаживание в `main.ts`. Интерфейс — `hud.ts`.

```ts
/**
 * Предел угла поворота колёс по скорости. На 200 км/ч физически полезны 2.6°:
 * больший угол требует бокового ускорения выше того, что держат шины, и просто
 * срывает передок. Игра, позволяющая полные 17° на любой скорости, ощущается
 * дёрганой и уходит в занос от каждого нажатия — поэтому ограничение по
 * скорости есть во всех гоночных симуляторах.
 */
export function steerLimitForSpeed(speedMs: number, wheelbaseM: number, maxRad: number): number {
  if (speedMs < 5) return maxRad
  const maxLateralMs2 = 4 * 9.81
  return Math.min(maxRad, Math.atan((wheelbaseM * maxLateralMs2) / (speedMs * speedMs)))
}
```
и применить в `step()`:
```ts
    const steerLimit = steerLimitForSpeed(speedMs, WHEELBASE_M, MAX_STEER_RAD)
    const steerRad = clamp(input.steer, -1, 1) * steerLimit
```

```ts
 * Порог выездов, после которого круг не засчитывается. В реальной F1 время
```

`smoothTowards` в `cameras.ts` — экспоненциальное приближение, устойчивое к переменному кадру:
```ts
/**
 * Экспоненциальное сглаживание, а не линейное: множитель считается через шаг
 * времени, поэтому камера ведёт себя одинаково на 60 и 144 кадрах в секунду.
 * Жёсткая привязка к болиду передаёт ему каждый рывок подвески — именно это
 * читается как «дёргается».
 */
export function smoothTowards(from: Vec3, to: Vec3, dt: number, rate: number): Vec3 {
  const k = 1 - Math.exp(-rate * dt)
  return {
    x: from.x + (to.x - from.x) * k,
    y: from.y + (to.y - from.y) * k,
    z: from.z + (to.z - from.z) * k,
  }
}
```
В `main.ts` держать текущую позицию камеры и цель взгляда в переменных и подтягивать их через `smoothTowards` каждый кадр. Кокпит сглаживать слабее внешней камеры: из кокпита задержка читается как расхлябанность.
