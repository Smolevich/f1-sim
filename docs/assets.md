# Ассеты

## Модель болида

`public/models/f1-car.glb` — 2.9 МБ, 73 меша, 49 тыс. треугольников.

Автор: **Blender458** (https://sketchfab.com/Blender458).
Лицензия: **CC Attribution 4.0** (http://creativecommons.org/licenses/by/4.0/).
Получено через FetchCFD: https://fetchcfd.com/view-project/4314-f1-3d-model

Атрибуция обязательна: выводится на экране старта и здесь.

### Замеры, от которых зависит загрузчик

Модель лежит вдоль Z носом на +Z, ось симметрии смещена на X = 0.645, днище на Y = -0.011.

| Величина | В единицах модели | После масштаба |
|---|---|---|
| длина | 4.458 | 5.30 м |
| колёсная база | 3.03 | 3.60 м (физика) |
| колея | 1.09 | 1.30 м |
| тормозной диск | 0.423 | 0.50 м |

Масштаб (1.188) берётся по колёсной базе, а не по длине: физика ставит колёса на ±1.8 м,
и подгонка по длине развела бы их на 3.83 м.

Покрышек в модели нет — это CFD-геометрия, резину снимали для расчёта потока.
`f1-model.ts` надевает на диски цилиндры радиусом 0.36 м.

## Ливреи

Только цвета. Логотипы, шрифты и названия команд — товарные знаки, а репозиторий
публичный, поэтому команды в `liveries.ts` названы по цвету и городу базы.
