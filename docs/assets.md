# Ассеты

## Модель болида

`public/models/chassis-draco.glb`, `public/models/wheel-draco.glb`

Источник: [pmndrs/racing-game](https://github.com/pmndrs/racing-game), лицензия репозитория MIT.
Проект заявляет, что использует **только CC0-ассеты** («100% open source and community
built, CC0 assets only»), поэтому модели пригодны для публичного репозитория без атрибуции.

Сжаты Draco — для загрузки нужен `DRACOLoader` вместе с `GLTFLoader`.

Ливреи и логотипы реальных команд не используются: перекраска своя.
