# f1-sim

Браузерный симулятор Формулы-1 на three.js и Rapier. Первая версия — сессия
квалификации: один круг на время, призрак лучшего круга, leaderboard топ-5.

## Разработка

```bash
npm install
npm run dev      # dev-сервер
npm test         # vitest
npm run build    # production-сборка в dist/
```

Требуется Node 24.

Спека и план — в `docs/superpowers/`.
